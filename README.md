# Engine Playground

[Alle öffentlichen Arbeitsproben im Überblick](https://github.com/adrienwottke-stack/project-portfolio)
Interaktiver Motoren-Lernsimulator mit 3D-Ansicht, Kühlungsmodell und nativer Audio-Bridge.

## Projekt und Beitrag

Portfolio-Arbeitsprobe von Adrien Wottke, Maschinenbaustudent mit Interesse an Engineering, Software und praktischen KI-Anwendungen. Der gezeigte Stand entstand unter Einsatz von KI-Werkzeugen. Vorgefertigte Frameworks und Drittanbieter-Komponenten bleiben Beiträge ihrer jeweiligen Urheber.

**Technologien:** TypeScript, Three.js, Vite, C++.

## Einstieg

```sh
npm ci
npm run dev
```

Benötigte Zugänge und Dienste müssen mit eigenen Werten eingerichtet werden. Diese Kopie enthält keine Zugangsdaten und verbindet sich nicht automatisch mit einer bestehenden Betriebsdatenbank. Vor dem Start Konfiguration und Paket-Skripte prüfen.

## Stand und Grenzen

Der native Kern basiert auf Engine Simulator von Ange Yaghi. Eigene Arbeit umfasst die Weboberfläche, Integration, Lernmodelle und Steuerung. KI-Werkzeuge unterstützten die Entwicklung. Echtzeitaudio auf dem geteilten Server bleibt eingeschränkt.

Snapshot für Bewerbungen vom 25. Oktober 2026. Der Upload ist kein neuer Funktions-, Leistungs- oder Live-Nachweis. Die Originalprojekte werden unabhängig weiterentwickelt; diese Kopie synchronisiert sich nicht automatisch.

## Inhalt und Herkunft

Enthalten sind ausgewählte Quelltexte, Konfiguration und vorhandene Tests. Ausgeschlossen sind Git-Historie, Laufzeitdaten, lokale Zugänge, private Exporte, persönliche Medien und Betriebsprotokolle. Vorhandene Lizenzhinweise von Drittanbietern bleiben erhalten. Eine Veröffentlichung dieser Arbeitsprobe erteilt keine pauschale Lizenz an Marken oder fremden Assets.

25. Oktober 2026: TypeScript-Prüfung und Produktionsbuild erfolgreich. Für vorhandene Regressionstests sind ausschließlich erforderliche eingefrorene Quellcode-Fixtures enthalten. Keine neue native Audio- oder Live-Abnahme.
